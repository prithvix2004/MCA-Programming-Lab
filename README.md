# MCA Programming Lab

A Python practice repository for MCA (Master of Computer Applications) programming lab exercises. It contains beginner-friendly programs covering core Python concepts such as integer operations, lists, functions, list comprehensions, strings, and dictionaries.

## Overview

This repository is organized by topic and includes multiple solved lab questions with simple Python implementations. The programs are designed for learning and practice, with examples that demonstrate fundamental programming logic and Python syntax.

## Topics Covered

### 1. Integer Operations
Programs covering:
- Area of a circle
- Largest of three numbers
- Computing n + nn + nnn
- GCD of two numbers

### 2. List Operations
Programs covering:
- Creating and displaying lists
- Accessing elements by index
- Removing odd/even values
- Replacing numbers greater than 100
- Comparing two lists by length, sum, and common elements

### 3. Function Programs
Programs covering:
- Simple function definitions
- Greeting with user input
- Sum and product of three numbers
- Leap year generation using functions

### 4. List Comprehension
Programs covering:
- Filtering positive values
- Squaring elements
- Extracting vowels from a word
- Finding ASCII values of characters

### 5. String and Dictionary Operations
Programs covering:
- Counting occurrences of a character in names
- Replacing repeated characters in a string
- Swapping first and last characters
- Extracting file extensions
- Counting word frequency in a sentence
- Working with color lists
- Dictionary creation, sorting, and merging

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/prithvix2004/MCA-Programming-Lab.git
```

2. Open any `.py` file in Python IDE or VS Code.

3. Run it using Python:

```bash
python "1. Integer Operations/1. Integer Operations Questions with Answers.py"
```

You can replace the path with any file from the repository.
