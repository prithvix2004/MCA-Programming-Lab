# MCA Programming Lab

## About the Repository

This repository contains Python programs developed as part of the MCA (Master of Computer Applications) Programming Lab curriculum. The exercises are designed to strengthen foundational programming concepts, problem-solving skills, and practical implementation techniques using Python.

The repository is organized by topic and includes solutions to a range of lab-based questions covering basic programming constructs, list processing, function-based problem solving, list comprehensions, and string/dictionary operations.

## Objectives

The primary objectives of this repository are to:

- practice core Python programming concepts
- implement laboratory questions systematically
- improve logical and analytical reasoning
- reinforce fundamentals of data structures and string processing
- support academic learning and revision

## Topics Covered

### 1. Integer Operations
This section includes basic arithmetic and logic-based programs such as:

- calculating the area of a circle
- finding the largest of three numbers
- computing n + nn + nnn
- determining the greatest common divisor (GCD) of two integers

### 2. List Operations
This section focuses on list handling and manipulation, including:

- creation and display of lists
- access to specific list elements
- filtering of even/odd values
- replacing values greater than a threshold
- comparing lists based on length, sum, and common elements

### 3. Function Programs
This section introduces modular programming with Python functions, covering:

- function definition and execution
- greeting programs using user input
- calculating sum and product of numbers
- identifying leap years within a range

### 4. List Comprehension
This section demonstrates Python's concise functional style through:

- filtering positive numbers
- generating squares of values
- selecting vowels from a word
- deriving ordinal values of characters

### 5. String and Dictionary Operations
This section focuses on text processing and dictionary-based data handling, including:

- counting repeated characters in names
- replacing repeated characters in strings
- swapping first and last letters
- extracting file extensions
- counting word frequencies in a sentence
- working with color lists
- sorting and merging dictionaries

## Programming Environment

The programs in this repository are written in Python 3 and can be executed using:

- Python IDLE
- VS Code
- PyCharm
- any Python-compatible interpreter

## How to Run the Programs

1. Clone the repository:

```bash
git clone https://github.com/prithvix2004/MCA-Programming-Lab.git
```

2. Navigate to the project directory:

```bash
cd MCA-Programming-Lab
```

3. Run a Python file using:

```bash
python "1. Integer Operations/1. Integer Operations Questions with Answers.py"
```

Replace the file path with the desired program from the repository.
